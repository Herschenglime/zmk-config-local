# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A ZMK firmware config for a 34-key split keyboard (Cradio/Sweep layout, `nice_nano_v2` boards, shield `cradio_%PART%`). It builds with Nix via [zmk-nix](https://github.com/lilyinstarlight/zmk-nix); there is no west workspace checked in.

## Commands

```bash
nix build              # build firmware (left + right halves) into ./result
nix flake check        # what CI runs (plus nix build)
nix run .#flash        # flash the built firmware
nix run .#update       # update west deps / zephyrDepsHash helper
```

`.envrc` uses `use flake`, so direnv gives a dev shell with the ZMK toolchain. There are no tests or linters.

When `config/west.yml` changes (or ZMK upstream moves), `zephyrDepsHash` in `flake.nix` goes stale and CI breaks. Run `nix run .#update`, or build and copy the expected hash from the error, then update `flake.nix`. Recent history shows this happening.

## Architecture

All keyboard logic lives in `config/cradio.keymap`, with Kconfig options in `config/cradio.conf` (sleep, BLE TX power, ZMK Studio, split battery proxy). `config/west.yml` pulls ZMK `main`. `flake.nix` filters sources by suffix, so new config files need a suffix in that list.

Key structure in `cradio.keymap`:
- **Layers** (`#define`d indices at the top): DEFAULT, GAMING, NAV, SYM, NUM, BLUETOOTH. NUM is not reached directly. A `conditional_layers` tri-layer activates it when NAV and SYM are both held. BLUETOOTH and GAMING are toggled by combos.
- **Key positions**: combos reference positions by index (0–9 top row, 10–19 home row, 20–29 bottom row, 30–33 thumbs, left half first). Check the numbering before editing any `key-positions`.
- **Custom behaviors**: `as` (auto-shift: tap = key, hold = shifted key; used through the `AS(keycode)` macro, which is applied to nearly every key on DEFAULT), `tph` (tap-preferred hold-tap), `smt`/`mo_tog`, and sticky keys (`&sk`, overridden to 2s with `lazy`/`quick-release`) for the `HRML`/`HRMR` home-row-mod macros.
- **Combos** supply most punctuation, brackets, Esc/Tab/Del/Backspace, and the mod key. `LEFT_EXCLUSION` disables a combo on NAV and `RIGHT_EXCLUSION` on SYM (the layers where that half's home row holds sticky mods).
- **Layout diagram**: `docs/layout.svg` is a quick-reference picture of every layer and combo, generated by `python3 docs/gen_layout_svg.py`. The layer data in that script is hand-maintained, so update it and regenerate whenever `cradio.keymap` changes.
- Large commented-out blocks (an unused `sm` behavior, an old double-quote combo, an empty layer template) are deliberate notes to self; leave them in place.
